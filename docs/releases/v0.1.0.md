# v0.1.0 – Public Beta / 首个开源预览版

## Overview / 项目概述

This is the first public beta of **Shifu Zaima / 师傅在吗**, an education-oriented WeChat Mini Program for mentoring, lesson-plan review, teaching-video analysis, and teaching Q&A.

这是“师傅在吗”微信小程序的首个公开测试版本，覆盖教师指导、教案修改、试讲分析和教学问答等场景。

> This is a source release, not a hosted service or an installable package. GitHub provides the ZIP and TAR.GZ archives automatically. / 本版本是源码 Release，不是托管服务或传统安装包；源码 ZIP 和 TAR.GZ 由 GitHub 自动提供。

## Included / 本版本内容

- 27 Mini Program pages / 27 个小程序页面
- 11 authenticated Cloud Functions / 11 个带鉴权流程的云函数
- Lesson-plan review and guidance-order workflows / 教案精修与指导订单流程
- Teaching-video asynchronous analysis adapter / 试讲视频异步分析适配器
- Teaching Q&A, content, favorites, profiles, and messaging / 教学问答、内容、收藏、档案与消息功能
- English and Chinese documentation / 中英文文档
- Repository validation, structural tests, and GitHub Actions / 仓库检查、结构测试与 GitHub Actions

## Run locally / 本地运行

1. Download `Source code (zip)` from this Release or clone the repository.
2. Import the project into WeChat Developer Tools.
3. Configure your own Mini Program AppID and Cloud Development environment.
4. Create the collections listed in [Deployment](https://github.com/YxCarl/miniprogram----/blob/v0.1.0/docs/DEPLOYMENT.md).
5. Deploy all directories under `cloudfunctions/`.
6. Configure `ZHIPU_API_KEY` only as a server-side environment variable if video analysis is enabled.
7. Compile and preview the Mini Program.

下载源码后，请使用微信开发者工具导入，并配置自己的 AppID、云开发环境、数据库集合和云函数。本 Release 不提供生产环境账号或凭据。

## Verification / 验证

```bash
npm install
npm test
```

Automated repository checks cover project structure, routing, configuration hygiene, and protected workflow invariants. Manual WeChat runtime verification requires the deployer's own AppID and cloud environment.

## Known limitations / 已知限制

- Mentor identity is self-selected in the demo and is not independently verified.
- Wallet, reward, and payment behavior is simulated and does not move real money.
- Database and storage rules must be configured and reviewed for each deployment.
- Enabling video analysis sends a temporary video URL to the configured external model provider; deployments must obtain consent and define retention/deletion rules.
- No production AppID, cloud identifier, private upload key, secret, or real user data is included.

对应限制：导师身份尚未正式审核；钱包与支付仅为演示；数据库和存储权限需要部署者配置；视频分析涉及外部模型服务；仓库不包含任何生产凭据或真实用户数据。

## Distribution / 分发方式

The full Mini Program is intentionally marked `private: true` in `package.json` because it is not an npm package. Deployment to WeChat is separate from this GitHub Release and can be performed with WeChat Developer Tools or `miniprogram-ci` using private credentials.

本项目不会发布 `.wxapkg`。微信平台上传与 GitHub 源码发布相互独立，上传密钥不得提交到 GitHub。

## Security

Read [SECURITY.md](https://github.com/YxCarl/miniprogram----/blob/v0.1.0/SECURITY.md) before deploying. Please report vulnerabilities privately and never include credentials, personal data, or classroom recordings in a public issue.
